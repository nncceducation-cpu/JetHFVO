# Jet HFVO — HFJV Call Tool

An interactive, mobile-first bedside reference for Bunnell Life Pulse high-frequency jet ventilation (HFJV) in extremely premature neonates.

**Live public tool:** https://jet-at-a-glance-hfjv.calnncc.chatgpt.site/

## What is included

- HFJV setup and starting-settings guidance
- Blood-gas interpretation and troubleshooting pathways
- Oxygenation and ventilation adjustment guidance
- No-chest-vibration safety check
- Weaning, recovery, and extubation-readiness prompts
- A printable color quick-reference sheet

## Run locally

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

## Important clinical notice

This educational tool is not a substitute for bedside assessment, institutional protocols, respiratory therapy expertise, or attending/neonatology judgment. Verify settings and treatment decisions against current local guidance and the Bunnell Life Pulse operator manual. In an unstable infant, prioritize immediate clinical assessment and escalation.
